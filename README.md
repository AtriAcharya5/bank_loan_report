📌 Project Overview
This repository features a comprehensive, interactive data analytics solution designed to track, monitor, and assess bank loan health. Utilizing a robust suite of metrics, the dashboard provides the executive team with high-level insights into loan distribution, financial risk factors, and month-over-month (MoM) operational performance to optimize lending strategies.

🎯 Purpose & Objectives
The primary goal of this project is to parse critical lending KPIs and uncover trends across diverse variables (time, geography, loan terms, and employment length). Additionally, the dashboard distinguishes between "Good Loans" and "Bad Loans" to give stakeholders immediate clarity on portfolio quality and financial risk mitigation.

🛠️ Tools & Technologies UsedPower BI Desktop
– For data modeling, visualization design, and report building.
DAX (Data Analysis Expressions) – To create complex dynamic measures and time-intelligence KPIs (e.g., MTD and MoM calculations).
Power Query / ETL – For data transformation, data cleaning, and schema optimization.

Total Loan Amount Funded: $435.76M (MTD: $54M, up 13.04% MoM).
Total Amount Received: $473.07M, showcasing healthy overall collection returns.

2. Portfolio Quality BreakdownGood Loans (86.18%):
Represents the vast majority of the bank's portfolio, with $370M funded and $436M successfully collected.
Bad Loans (13.82%): Accounts for $66M in funded loans, yielding only $37M in collections. 
This segment indicates an average interest rate premium (14.25%) and a higher average DTI (14.74%).

3. Structural Trends
Term Preference: Short-term loans (36 months) dominate the portfolio, accounting for 62.66% ($273.04M) of the total funded volume compared to 60-month terms.
Borrower Profile: Borrowers with 10+ years of employment represent the highest concentration of total loan value ($116M).Seasonality:
Loan disbursement shows consistent month-over-month growth throughout the year, peaking sharply in December ($54M).

.🏁 Conclusion
The dashboard successfully provides a clear, data-driven window into the bank’s credit operations. While the portfolio maintains a strong healthy loan baseline at 86.18%, the deeper granular view highlights that non-performing assets ("Bad Loans") correlate directly with higher DTI percentages and elevated interest rates. Moving forward, these insights empower credit risk teams to refine strict underwriting thresholds for high-DTI applicants and optimize seasonal credit allocations
